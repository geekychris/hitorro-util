# Hitorro Util

This is the standalone utility library extracted from the Hitorro project.

## Overview

The hitorro-util library provides core utility functionality for the Hitorro system, including:
- JSON type system utilities
- File system utilities
- Network utilities
- Data processing utilities
- Various helper classes and tools

## Building

To build the project:

```bash
mvn clean install
```

## Maven Dependency

To use this library in another Maven project:

```xml
<dependency>
    <groupId>ht</groupId>
    <artifactId>hitorro-util</artifactId>
    <version>2.0</version>
</dependency>
```

## Requirements

- Java 19 or higher
- Maven 3.x
